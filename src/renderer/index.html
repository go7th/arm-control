操作说明 OPERATION MANUAL ▾

快速上手

  1. 点「选择硬件」，选中 USB-TTL 串口（已接机械臂 USART1）
  2. 按住中央大按钮说话，说完松开
  3. 识别 → 校验 → 下发，TX 栏显示发出的协议指令

安全

  • 任何时候说「急停 / 停止 / 停 / 住嘴」→ 立即 $DST!，不经过网络
  • Esc 键同款急停（按钮不在界面，快捷键常驻）
  • 参数越界（坐标/动作组号）自动拒绝执行

口令速查

急停 / 停止 / 停$DST!
复位 / 回中 / 归位$DJR!
蜂鸣 / 滴一声$BEEP!
第3组 / 动作组3$DGS:3!
2到5组循环3遍$DGT:2-5,3!
移到 (200,250,250)$KMS:200,250,250,1000!
其他口语（转圈两遍…）云 LLM 解析

接线

USB-TTL：TX→臂 RX、RX→臂 TX、GND→GND，115200 8N1（USART1）。

密钥配置（界面无设置项）

写入项目根目录 .env.local：

LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-...
LLM_MODEL=deepseek-chat
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=eastasia

或 ~/Library/Application Support/arm-control/config.json（重新启动生效）。
